# Overview
Similar to Turtlebot 3

- Features
    - Raspberry Pi 5
    - Arduino
    - DC Motors
    - Odometry
        - Encoders
        - IMU
        - LiDAR
    - SLAM (w/ LiDAR)
    - Obstacle Avoidance with PPO
